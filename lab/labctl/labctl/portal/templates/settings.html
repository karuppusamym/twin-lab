Database servers

Where a demo app's database lives. Twin Lab can run PostgreSQL or SQL Server itself in a container, with nothing to set up. To use a server your DBA prepared (SQL Server, Oracle or PostgreSQL), ask for a database (or Oracle service), an owner account that may create tables, and a bot account that may only read and change rows. Then list it in twinlab.local.yaml under databases:; the example is in twinlab.local.example.yaml. Passwords stay on this machine and are never shown. Each app picks its database on its page (Lab).
