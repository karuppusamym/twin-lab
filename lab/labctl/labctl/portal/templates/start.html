Try it on the sample

The showcase app is already built, with a UiPath bot that updates cases. Open it, press Start in its Lab, then Readiness. Record a session while you run the bot (or labctl harness run uipath-case-update), and look at its verdict.

A flow through several applications

Record it once on the Recordings page, every tab included. Twin Lab finds each application, you confirm the split, and each one gets its own brief and package, with where it sits in the flow.

Rules that keep you safe

  • Evidence, robot logs and data packs are stored locally. Review build packages before sharing them with a builder.
  • Only synthetic or masked data goes into a lab. Real data needs a mask receipt.
  • Bots get a database login that can change rows only, never the database itself.
  • A lab someone has reserved can be looked at, not changed.
