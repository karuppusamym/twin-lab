# Twin Lab on OpenShift: manifests to apply by hand

Generated by `labctl ocp render --all --manual`. One folder per app; each has its own `README.md` with the exact steps. The images are built inside the cluster from the branch named in each BuildConfig, so nothing comes from an outside registry. No file holds a secret value.

| App | Lab on OpenShift | Folder |
|---|---|---|
| `loandesk` | ONE pod with an init step, the lab agent and the app sharing the SQLite file's volume (PVC); no database pod | [loandesk/](loandesk/README.md) |
| `qtt` | a Postgres pod and its login-setup Job, the lab agent and the app in separate pods, with PVCs | [qtt/](qtt/README.md) |
| `showcase` | a Postgres pod and its login-setup Job, the lab agent and the app in separate pods, with PVCs | [showcase/](showcase/README.md) |

Check a folder before applying it (offline, no cluster needed):

```bash
labctl ocp check deploy/ocp
```

Then follow the folder's README: create the Secret by hand, `oc apply -f <folder>`, start the builds. To change the project, branch or options, render again; the test suite fails when these files no longer match what `labctl` renders.
